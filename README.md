# مدار تك

مرحباً بك في مستودع "مدار تك"، وهو مكان لأعرض فيه مشاريعي وتجربتي في تطوير واجهات الويب الأمامية.

## نبذة عن المشروع

هذا المستودع مخصص لتجميع مشاريع Front-End التي أعمل عليها، بما في ذلك:

- صفحات ويب متجاوبة
- تصميمات واجهات المستخدم
- تطبيقات صغيرة وتطبيقات تفاعلية
- تجربة مستخدم محسّنة
- ممارسات تطوير حديثة في HTML، CSS، JavaScript، وReact

## ما الذي سأضيفه هنا؟

- مشاريع عملية ومكتملة
- أمثلة تعليمية
- مكونات واجهة مستخدم قابلة لإعادة الاستخدام
- تطبيقات تجريبية وتحديات برمجية
- تحسينات مستمرة في مهارات تطوير الويب

## التقنيات التي أعمل عليها

- HTML5
- CSS3
- JavaScript
- React
- Bootstrap / Tailwind
- Git و GitHub

## قائمة المشاريع

- سيتم إضافة المشاريع هنا تدريجياً
- سيتم ربط كل مشروع مباشرةً بمجلد أو صفحة خاصة به

## التواصل

إذا كنت ترغب في التعاون أو الاستفسار عن أحد المشاريع، يمكنك التواصل معي عبر GitHub.

## ملاحظة

هذا المستودع يمثل مساحة لتوثيق تعلمي وتطويري في مجال تصميم وتطوير الواجهات الأمامية.
